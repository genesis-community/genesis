=head1 NAME

Genesis::Secret::RSA - Genesis secret type for RSA public/private key pairs

=head1 SYNOPSIS

  use Genesis::Secret;

  # Build an RSA key pair secret via the factory method
  my $secret = Genesis::Secret->build('rsa', 'kit', 'path/to/keypair',
    size => 4096,
  );

  # Build a fixed (non-rotatable) RSA key pair
  my $fixed = Genesis::Secret->build('rsa', 'kit', 'path/to/keypair',
    size => 2048,
    fixed => 1,
  );

  # Get the vault operator string for the public key
  my $op = $secret->vault_operator('public_key');
  print $op; # prints e.g. '(( vault meta.vault "/path/to/keypair:public" ))'

  # Get vault operators for all keys
  my $ops = $secret->vault_operator();
  print $ops->{public_key};  # prints vault operator for public key
  print $ops->{private_key}; # prints vault operator for private key

=head1 DESCRIPTION

C<Genesis::Secret::RSA> is the concrete C<Genesis::Secret> subclass for
RSA public/private key pair secrets. It manages RSA key pairs stored in
Vault under a single path with two keys: C<public> (the PEM-encoded public
key) and C<private> (the PEM-encoded private key).

The key pair is generated via C<safe rsa> and is validated using C<openssl>
to verify both keys are well-formed, that the public and private keys agree
(share the same modulus), and that the key size matches the configured bit
length.

Instances are created via C<< Genesis::Secret->build('rsa', ...) >>. Do not
instantiate this class directly.

=head1 METHODS

=head2 label

  my $label = $secret->label();

Returns the human-readable label C<'RSA key pair'> for this secret type.
Overrides the L<base class default|Genesis::Secret/label>.

B<Returns:> The string C<'RSA key pair'>.

  print $secret->label();
  # Returns: 'RSA key pair'

=head2 vault_operator

  my $op   = $secret->vault_operator($key);
  my $ops  = $secret->vault_operator();

Returns the Vault operator string for embedding the RSA key pair in a BOSH
manifest. Delegates to the parent L<_assemble_vault_operator|Genesis::Secret/_assemble_vault_operator> method to
format the final string.

B<Parameters:>

=over 4

=item * C<$key> - Optional. Which key to return an operator for. Accepts
C<'public'>, C<'public_key'>, C<'private'>, or C<'private_key'>.
If omitted, returns operators for both keys.

=back

B<Returns:> When C<$key> is provided, returns a single Vault operator string
for the requested key component. When C<$key> is omitted, returns a hashref
with keys C<'public_key'> and C<'private_key'>, each mapping to its
respective Vault operator string.

B<Errors:>

=over 4

=item * Calls C<bug()> with C<"Invalid key for vault_operator on %s secret (%s): %s">
(where the placeholders are the secret type, Vault path, and the invalid key
name) if C<$key> is not one of the accepted values. This indicates a
programming error, not a user error.

=back

  # Get operator for a single key
  my $op = $secret->vault_operator('public_key');
  # Returns: '(( vault meta.vault "/path/to/keypair:public" ))'

  # Get operators for all keys
  my $ops = $secret->vault_operator();
  # Returns: {
  #   public_key  => '(( vault meta.vault "/path/to/keypair:public" ))',
  #   private_key => '(( vault meta.vault "/path/to/keypair:private" ))',
  # }

=head1 INTERNAL METHODS

These methods are internal to the implementation. They may change without
notice and should not be called directly.

=head2 _description

  my ($label, @features) = $secret->_description();

Returns a list describing the RSA key pair for use by the parent L<describe|Genesis::Secret/describe> method. The list contains the uppercased type with C<"public/private keypair">,
the configured key size in bits, and the string C<'fixed'> if the secret is
marked fixed (or nothing for that slot if not fixed).

=head2 _required_constructor_opts

  my @opts = $secret->_required_constructor_opts();

Returns C<('size')>, indicating that the C<size> option (key bit length) is
required when constructing an RSA secret.

=head2 _optional_constructor_opts

  my @opts = $secret->_optional_constructor_opts();

Returns C<('fixed')>, indicating that the C<fixed> boolean option is accepted
but not required.

=head2 _required_value_keys

  my @keys = $secret->_required_value_keys();

Returns C<('private', 'public')>, the two keys that must be present in the
stored value hashref for the secret to be considered complete.

=head2 _validate_value

  my ($results, @order) = $secret->_validate_value(%opts);

Validates the stored RSA key pair using C<openssl>. Checks that the private
key is a valid RSA private key, that the public key is a valid RSA public
key, that the public key's bit length matches the configured C<size>, and
that the public and private keys agree (share the same modulus).

B<Parameters:>

=over 4

=item * C<%opts> - Options hash. Accepts:

=over 4

=item * C<allow_oversized> - If true, accepts keys larger than the configured
C<size> (only requires the key to be at least C<size> bits). Defaults to
false (exact match required).

=back

=back

B<Returns:> A list of C<(\%results, @order)> where C<%results> is a hash
mapping validation names (C<'priv'>, C<'pub'>, C<'agree'>, C<'size'>) to
C<[$status, $message]> pairs, and C<@order> is C<('priv', 'pub', 'agree',
'size')> giving the display order. The C<'agree'> result is only populated
when both the private and public key validations pass.

  my ($results, @order) = $secret->_validate_value();
  # Returns: (
  #   { priv  => [1,    'Valid private key'],
  #     pub   => [1,    'Valid public key'],
  #     agree => [1,    'Public/Private key agreement'],
  #     size  => ['ok', '4096 bits'], },
  #   'priv', 'pub', 'agree', 'size'
  # )

  my ($results2, @order2) = $secret->_validate_value(allow_oversized => 1);
  # Returns: size entry uses 'N bits minimum' label and passes if actual >= configured size

=head2 __get_safe_command_for_generate

  my @cmd = $secret->__get_safe_command_for_generate($action, %opts);

Constructs the C<safe rsa> command argument list for generating the key pair.
Appends C<--no-clobber> when C<$action> is C<'add'> or when the secret is
marked as fixed.

B<Parameters:>

=over 4

=item * C<$action> - The generation action: C<'add'> or C<'rotate'>.

=item * C<%opts> - Currently unused; accepted for interface compatibility.

=back

B<Returns:> A list beginning with C<'rsa'>, followed by the configured key
size and the full Vault path, optionally with C<'--no-clobber'>.

  my @cmd = $secret->__get_safe_command_for_generate('add');
  # Returns: ('rsa', 4096, 'secret/myenv/path/to/keypair', '--no-clobber')

  my @cmd2 = $secret->__get_safe_command_for_generate('rotate');
  # Returns: ('rsa', 4096, 'secret/myenv/path/to/keypair')
  # (no --no-clobber unless secret is marked fixed)

=head2 _get_safe_command_for_add

  my @cmd = $secret->_get_safe_command_for_add();

Delegates to C<__get_safe_command_for_generate> with action C<'add'>.
Called by the parent L<get_safe_command_for|Genesis::Secret/get_safe_command_for> dispatch for the
C<'add'> action.

B<Returns:> The same list as C<__get_safe_command_for_generate> with
C<--no-clobber> always appended.

=head2 _get_safe_command_for_rotate

  my @cmd = $secret->_get_safe_command_for_rotate();

Delegates to C<__get_safe_command_for_generate> with action C<'rotate'>.
Called by the parent L<get_safe_command_for|Genesis::Secret/get_safe_command_for> dispatch for the
C<'rotate'> action.

B<Returns:> The same list as C<__get_safe_command_for_generate>, with
C<--no-clobber> appended only if the secret is marked fixed.

=head2 _import_from_credhub

  my ($status, $msg) = $secret->_import_from_credhub($value);

Imports RSA key pair data fetched from CredHub. Expects C<$value> to be a
hashref with keys C<'private_key'> and C<'public_key'>. Maps them to the
internal Vault keys C<'private'> and C<'public'>, then calls the parent L<set_value|Genesis::Secret/set_value> and L<save|Genesis::Secret/save> methods.

B<Parameters:>

=over 4

=item * C<$value> - The CredHub value hashref. Must contain
C<'private_key'> and C<'public_key'>.

=back

B<Returns:> A list of C<('ok')> on success, or C<('error', $message)> on
failure. Failure messages include:

=over 4

=item * C<"expecting a hash, got a E<lt>typeE<gt>"> if C<$value> is not a
hashref, where C<E<lt>typeE<gt>> is the ref type (e.g. C<'ARRAY'>) or an
empty string if C<$value> is a plain scalar.

=item * C<"missing keys in credhub secret: E<lt>keysE<gt>"> if C<$value>
does not contain both required keys, listing the missing key names.

=back

  # Successful import
  my ($status) = $secret->_import_from_credhub({
    private_key => '-----BEGIN RSA PRIVATE KEY-----...',
    public_key  => '-----BEGIN PUBLIC KEY-----...',
  });
  # Returns: ('ok')

  # Wrong type: array ref
  my ($status2, $msg2) = $secret->_import_from_credhub([]);
  # Returns: ('error', 'expecting a hash, got a ARRAY')

  # Wrong type: plain scalar (ref() returns empty string)
  my ($status3, $msg3) = $secret->_import_from_credhub('not-a-hash');
  # Returns: ('error', 'expecting a hash, got a ')

  # Missing keys
  my ($status4, $msg4) = $secret->_import_from_credhub({ private_key => '...' });
  # Returns: ('error', 'missing keys in credhub secret: public_key')
