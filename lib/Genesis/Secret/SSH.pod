=head1 NAME

Genesis::Secret::SSH - Genesis secret type for SSH key pairs

=head1 SYNOPSIS

  use Genesis::Secret;

  # Build an SSH key pair secret via the factory method
  my $secret = Genesis::Secret->build('ssh', 'kit', 'path/to/ssh-key',
    size => 4096,
  );

  # Build a fixed (non-rotatable) SSH key pair secret
  my $fixed = Genesis::Secret->build('ssh', 'kit', 'path/to/ssh-key',
    size => 2048,
    fixed => 1,
  );

  # Check the human-readable label for this secret type
  print $secret->label();
  # Returns: 'SSH key pair'

  # Get a vault operator for use in a BOSH manifest
  my $op = $secret->vault_operator('public_key');
  print $op;
  # Returns: e.g. '(( vault meta.vault "/path/to/ssh-key:public" ))'

=head1 DESCRIPTION

C<Genesis::Secret::SSH> is the concrete C<Genesis::Secret> subclass for SSH
key pair secrets. It manages an SSH key pair stored in Vault under a single
path with three keys: C<private> (the PEM-encoded private key), C<public>
(the OpenSSH-format public key), and C<fingerprint> (the public key
fingerprint).

The key pair is generated via C<safe ssh> and validated using C<ssh-keygen>
to verify that the private key is well-formed, the public key is valid, the
public and private keys agree with each other, and that the key size matches
the configured bit length.

Instances are created via C<< Genesis::Secret->build('ssh', ...) >>. Do not
instantiate this class directly.

=head1 METHODS

=head2 label

  my $label = $secret->label();

Returns the human-readable label C<'SSH key pair'> for this secret type.
Overrides the L<base class default|Genesis::Secret/label>.

B<Returns:> The string C<'SSH key pair'>.

  print $secret->label();
  # Returns: 'SSH key pair'

=head2 vault_operator

  my $op     = $secret->vault_operator($key);
  my $op_map = $secret->vault_operator();

Returns a Vault operator string (or map of strings) suitable for use in a
BOSH manifest.

When C<$key> is provided, returns a single Vault operator string for that
component. Accepted values for C<$key>:

=over 4

=item * C<'public'> or C<'public_key'> - the OpenSSH-format public key

=item * C<'private'> or C<'private_key'> - the PEM-encoded private key

=item * C<'fingerprint'> or C<'public_key_fingerprint'> - the public key fingerprint

=back

When C<$key> is omitted, returns a hashref mapping each of the canonical
key names (C<'public_key'>, C<'private_key'>, C<'public_key_fingerprint'>)
to its corresponding Vault operator string.

B<Parameters:>

=over 4

=item * C<$key> - Optional. The SSH key component to retrieve the operator
for. Accepts short or long forms as listed above.

=back

B<Returns:> A Vault operator string (e.g., C<'(( vault meta.vault
"/path/to/ssh-key:public" ))'>) when C<$key> is given, or a hashref of
three such strings when C<$key> is omitted.

B<Errors:>

=over 4

=item * Dies via C<bug()> with C<"Invalid key for vault_operator on %s secret (%s): %s">
if C<$key> is provided but does not match any of the accepted values. C<%s>
is the secret type, the Vault path, and the invalid key name, respectively.

=back

  # Single operator for the public key
  my $op = $secret->vault_operator('public_key');
  print $op;
  # Returns: '(( vault meta.vault "/path/to/ssh-key:public" ))'

  # All three operators at once
  my $ops = $secret->vault_operator();
  print $ops->{private_key};
  # Returns: '(( vault meta.vault "/path/to/ssh-key:private" ))'

=head1 INTERNAL METHODS

These methods are internal to the implementation. They may change without
notice and should not be called directly.

=head2 _description

  my ($label, @features) = $secret->_description();

Returns a list describing the SSH key pair for use by the parent L<describe|Genesis::Secret/describe> method. The list contains a string of the form C<"SSH
public/private keypair">, the configured size in bits (e.g., C<"4096
bits">), and the string C<'fixed'> if the secret is marked fixed (or
C<undef> for that slot if not fixed).

=head2 _validate_constructor_opts

  my ($args, $errors) = $class->_validate_constructor_opts($path, %opts);

Validates the constructor options for an SSH key pair secret. Checks that
C<size> is present and is an integer in the range 1024-16384, and that no
unrecognised options are supplied.

B<Parameters:>

=over 4

=item * C<$path> - The Vault path for this secret (passed through for
error reporting).

=item * C<%opts> - The constructor options. Recognised keys:

=over 4

=item * C<size> - Required. The key size in bits; must be an integer
between 1024 and 16384 inclusive.

=item * C<fixed> - Optional. Boolean; if true the secret cannot be
overwritten by a rotate operation.

=back

=back

B<Returns:> On success, a single-element list C<($args_hashref)>. On
failure, a two-element list C<($orig_opts_hashref, $errors_arrayref)>
where C<$errors_arrayref> contains one or more of:

=over 4

=item * C<"Missing required 'size' argument">

=item * C<"Invalid size argument: expecting 1024-16384, got $size">
where C<$size> is the supplied value.

=item * C<"Invalid '$name' argument specified"> for each unrecognised
option key.

=back

  my ($args) = $secret->_validate_constructor_opts('my/path', size => 4096, fixed => 1);
  # Returns: ({size => 4096, fixed => 1})

  my ($orig, $errors) = $secret->_validate_constructor_opts('my/path', size => 512);
  # Returns: ({size => 512}, ['Invalid size argument: expecting 1024-16384, got 512'])

=head2 _required_value_keys

  my @keys = $secret->_required_value_keys();

Returns C<('private', 'public', 'fingerprint')>, the three keys that must
be present in the stored value hashref for the secret to be considered
complete.

=head2 _validate_value

  my ($results, @order) = $secret->_validate_value(%opts);

Validates the stored SSH key pair using C<ssh-keygen>. Uses named FIFOs to
feed key material to C<ssh-keygen> without writing to the filesystem.

Checks performed:

=over 4

=item * C<priv> - Whether C<ssh-keygen -y> can derive a public key from
the stored private key.

=item * C<pub> - Whether C<ssh-keygen -B> can compute a fingerprint from
the stored public key.

=item * C<agree> - Whether the public key derived from the private key
matches the stored public key (only checked when the private key is valid).

=item * C<size> - Whether the bit length of the public key matches the
configured C<size> (only checked when the public key is valid).

=back

B<Parameters:>

=over 4

=item * C<%opts> - Options hash. Accepts:

=over 4

=item * C<allow_oversized> - If true, accepts a key larger than the
configured C<size> (only requires the key to be at least C<size> bits).
Defaults to false (exact match required).

=back

=back

B<Returns:> A list of C<(\%results, @order)> where C<%results> is a hash
mapping validation names to C<[$status, $message]> pairs, and C<@order>
is C<('priv', 'pub', 'agree', 'size')> giving the display order. Status
values are C<1>/C<0> for pass/fail checks and C<'ok'>/C<'warn'> for the
size check.

  my ($results, @order) = $secret->_validate_value();
  # Returns: (\%results, 'priv', 'pub', 'agree', 'size')

  my ($results, @order) = $secret->_validate_value(allow_oversized => 1);
  # Returns: (\%results, 'priv', 'pub', 'agree', 'size')
  # with size check requiring >= configured bits

=head2 __get_safe_command_for_generate

  my @cmd = $secret->__get_safe_command_for_generate($action, %opts);

Constructs the C<safe ssh> command argument list for generating the SSH key
pair. Appends C<--no-clobber> when C<$action> is C<'add'> or when the
secret is marked as fixed.

B<Parameters:>

=over 4

=item * C<$action> - The generation action: C<'add'> or C<'rotate'>.

=item * C<%opts> - Currently unused; accepted for interface compatibility.

=back

B<Returns:> A list beginning with C<'ssh'>, followed by the configured key
size and the full Vault path, optionally with C<'--no-clobber'>.

  my @cmd = $secret->__get_safe_command_for_generate('add');
  # Returns: ('ssh', 4096, 'secret/myenv/path/to/ssh-key', '--no-clobber')

  my @cmd = $secret->__get_safe_command_for_generate('rotate');
  # Returns: ('ssh', 4096, 'secret/myenv/path/to/ssh-key')

=head2 _get_safe_command_for_add

  my @cmd = $secret->_get_safe_command_for_add();

Delegates to C<__get_safe_command_for_generate> with action C<'add'>.
Called by the parent L<get_safe_command_for|Genesis::Secret/get_safe_command_for> dispatch for the C<'add'>
action.

B<Returns:> The same list as C<__get_safe_command_for_generate> with
C<--no-clobber> always appended.

=head2 _get_safe_command_for_rotate

  my @cmd = $secret->_get_safe_command_for_rotate();

Delegates to C<__get_safe_command_for_generate> with action C<'rotate'>.
Called by the parent L<get_safe_command_for|Genesis::Secret/get_safe_command_for> dispatch for the C<'rotate'>
action.

B<Returns:> The same list as C<__get_safe_command_for_generate>, with
C<--no-clobber> appended only if the secret is marked fixed.

=head2 _import_from_credhub

  my ($status, $msg) = $secret->_import_from_credhub($value);

Imports an SSH key pair from a CredHub secret value. Expects C<$value> to
be a hashref containing the keys C<private_key>, C<public_key>, and
C<public_key_fingerprint>. Maps those to the internal storage keys
C<private>, C<public>, and C<fingerprint>, sets the value, and saves it
to the backing store.

B<Parameters:>

=over 4

=item * C<$value> - A hashref fetched from CredHub containing the SSH key
pair components.

=back

B<Returns:> C<('ok')> on success, or C<('error', $message)> on failure.
Error messages:

=over 4

=item * C<'expecting a hash, got a string'> if C<$value> is not a hashref
(or C<'expecting a hash, got a E<lt>refE<gt>'> naming the actual reference
type).

=item * C<"missing keys in credhub secret: $keys"> where C<$keys> is a
comma-separated list of the missing required key names.

=back

  my ($status) = $secret->_import_from_credhub({
    private_key           => '-----BEGIN RSA PRIVATE KEY-----...',
    public_key            => 'ssh-rsa AAAA...',
    public_key_fingerprint => 'SHA256:...',
  });
  # Returns: ('ok')

  my ($status, $msg) = $secret->_import_from_credhub('not-a-hash');
  # Returns: ('error', 'expecting a hash, got a string')
