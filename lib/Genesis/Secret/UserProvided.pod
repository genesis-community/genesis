=head1 NAME

Genesis::Secret::UserProvided - Genesis secret type for user-provided values

=head1 SYNOPSIS

  use Genesis::Secret;

  # Build a user-provided secret via the factory method
  my $secret = Genesis::Secret->build('user_provided', 'kit', 'path/to/secret',
    prompt => 'Enter the database password',
  );

  # Build a sensitive (hidden-input) user-provided secret
  my $sensitive = Genesis::Secret->build('user_provided', 'kit', 'path/to/secret',
    prompt    => 'Enter the API key',
    sensitive => 1,
  );

  # Build a multi-line user-provided secret
  my $multiline = Genesis::Secret->build('user_provided', 'kit', 'path/to/secret',
    prompt    => 'Paste the certificate PEM block',
    multiline => 1,
  );

  # Get the vault operator string
  my $op = $secret->vault_operator();
  print $op; # prints e.g. '(( vault meta.vault "/path/to/secret:value" ))'

=head1 DESCRIPTION

C<Genesis::Secret::UserProvided> is the concrete C<Genesis::Secret> subclass
for secrets whose values are supplied interactively by the operator at
deployment time. Rather than generating a value automatically, this secret
type prompts the user via the terminal when C<add> or C<rotate> is performed.

Three input modes are supported:

=over 4

=item * B<Single-line> (default) - Uses C<safe ask> to collect a visible
single-line value, or C<safe set> when C<sensitive> is true (hides input and
requires confirmation).

=item * B<Multi-line> - When C<multiline> is true, opens an editor-style
block prompt via the C<prompt_for_block> function in C<Genesis::UI> and stores the result via
C<safe set> to a temporary file.

=item * B<Fixed> - When C<fixed> is true, C<--no-clobber> is passed to
C<safe>, preventing an existing value from being overwritten.

=back

Instances are created via C<< Genesis::Secret->build('user_provided', ...) >>.
Do not instantiate this class directly.

=head1 METHODS

=head2 label

  my $label = $secret->label($action);

Returns the human-readable label C<'User-provided'> for this secret type.
Overrides the L<base class default|Genesis::Secret/label>.

C<$action> is accepted for interface compatibility with the parent class but
is not used by this method. The return value is always the same regardless
of the action.

B<Parameters:>

=over 4

=item * C<$action> - Accepted for interface compatibility; not used. May be
any value or omitted entirely.

=back

B<Returns:> The string C<'User-provided'>.

  print $secret->label();        # prints 'User-provided'
  print $secret->label('add');   # prints 'User-provided'

=head2 vault_operator

  my $op = $secret->vault_operator($req_key);

Returns the Vault operator string for embedding this secret in a BOSH
manifest. Delegates to the parent L<_assemble_vault_operator|Genesis::Secret/_assemble_vault_operator> method
to format the final string.

The path used for the operator is derived from the inherited L<path|Genesis::Secret/path> method.
If the path already contains a C<:key> suffix, that key is used; otherwise the
C<default_key> is appended.

B<Parameters:>

=over 4

=item * C<$req_key> - Optional. Reserved for interface compatibility;
not used in the current implementation. The key component is always
derived from the path or C<default_key>.

=back

B<Returns:> A Vault operator string suitable for embedding in a BOSH
manifest.

  my $op = $secret->vault_operator();
  # Returns: '(( vault meta.vault "/path/to/secret:value" ))'

=head2 prompt_for_multiline_secret

  Genesis::Secret::UserProvided::prompt_for_multiline_secret($file, $prompt);

Presents a block-style prompt to the operator and writes the entered text
to C<$file>. Uses the C<prompt_for_block> function from C<Genesis::UI> to
collect multi-line input. Returns C<0> on completion.

This is a package-level function (not an instance method) used as a
callback in the command sequence built by C<__get_safe_command_for_generate>
for multi-line secrets.

B<Parameters:>

=over 4

=item * C<$file> - The path of the temporary file to write the collected
input to.

=item * C<$prompt> - The prompt string displayed to the operator.

=back

B<Returns:> C<0>.

  my $rc = Genesis::Secret::UserProvided::prompt_for_multiline_secret(
    '/tmp/secret_contents',
    'Paste the certificate PEM block',
  );
  # Returns: 0  (input written to /tmp/secret_contents)

=head1 INTERNAL METHODS

These methods are internal to the implementation. They may change without
notice and should not be called directly.

=head2 is_command_interactive

  my $bool = $secret->is_command_interactive($action);

Returns true if C<$action> is C<'add'> or C<'rotate'> (both require
interactive terminal input), and false for all other actions. Overrides
the L<base class|Genesis::Secret/is_command_interactive>, which always returns false.

B<Parameters:>

=over 4

=item * C<$action> - The action string to test (e.g., C<'add'>, C<'rotate'>,
C<'remove'>).

=back

B<Returns:> A true value for interactive actions (C<'add'> or C<'rotate'>),
false otherwise.

  print $secret->is_command_interactive('add');    # Returns: 1
  print $secret->is_command_interactive('rotate'); # Returns: 1
  print $secret->is_command_interactive('remove'); # Returns: 0

=head2 _required_constructor_opts

  my @opts = $secret->_required_constructor_opts();

Returns C<('prompt')>, indicating that the C<prompt> option (the text
shown to the operator) is required when constructing a user-provided secret.

=head2 _optional_constructor_opts

  my @opts = $secret->_optional_constructor_opts();

Returns C<('sensitive', 'multiline', 'subtype', 'fixed')>, the optional
construction options for a user-provided secret.

=over 4

=item * C<sensitive> - If true, hides input and requires confirmation via
C<safe set>.

=item * C<multiline> - If true, presents a block editor prompt and stores
the value from a temporary file.

=item * C<subtype> - Future-proofing field; may alter construction or
behaviour (e.g., for providing x509 certificates). Currently unused.

=item * C<fixed> - If true, passes C<--no-clobber> to C<safe>, preventing
an existing value from being overwritten during add or rotate.

=back

=head2 __get_safe_command_for_generate

  my @cmd = $secret->__get_safe_command_for_generate($action, %opts);

Constructs the command argument list for adding or rotating a
user-provided secret. If a controlling terminal is available
(C<in_controlling_terminal> is true), builds a prompt-and-store sequence.
If no controlling terminal is available, returns an empty list.

For single-line secrets, the sequence is:
C<prompt>, the prompt text, C<-->, C<ask|set>, path:key
(with C<--no-clobber> appended for C<'add'> or fixed secrets).
C<ask> is used for non-sensitive secrets; C<set> for sensitive ones.

For multi-line secrets, the sequence is:
a C<\&prompt_for_multiline_secret> code reference, the temp file path,
the prompt text, C<-->, C<set>, path@file
(with C<--no-clobber> appended for C<'add'> or fixed secrets).

B<Parameters:>

=over 4

=item * C<$action> - The action being performed: C<'add'> or C<'rotate'>.

=item * C<%opts> - Currently unused; accepted for interface compatibility.

=back

B<Returns:> A list of command components and arguments, or an empty list
if not running in a controlling terminal.

  # Single-line, non-sensitive, add action
  my @cmd = $secret->__get_safe_command_for_generate('add');
  # Returns: ('prompt', 'Enter the password', '--', 'ask',
  #           'secret/myenv/path/to/secret', 'value', '--no-clobber')

=head2 _get_safe_command_for_add

  my @cmd = $secret->_get_safe_command_for_add();

Delegates to C<__get_safe_command_for_generate> with action C<'add'>.
Called by the parent L<get_safe_command_for|Genesis::Secret/get_safe_command_for> dispatch for the
C<'add'> action. When a controlling terminal is available, the returned
command always includes C<--no-clobber>. Returns an empty list when no
controlling terminal is available.

Note: C<_get_safe_command_for_rotate> is defined alongside this method
and delegates to C<__get_safe_command_for_generate> with action
C<'rotate'>. It includes C<--no-clobber> only if the secret is marked fixed.

B<Returns:> The same command list as C<__get_safe_command_for_generate>,
or an empty list when no controlling terminal is present.

=head2 _import_from_credhub

  my ($status) = $secret->_import_from_credhub($value);

Imports a user-provided secret value fetched from CredHub. Sets the
secret's value to C<$value>, saves it to the backing store, and returns
C<('ok')>.

B<Parameters:>

=over 4

=item * C<$value> - The scalar value fetched from CredHub.

=back

B<Returns:> C<('ok')>.

  my ($status) = $secret->_import_from_credhub('my-secret-value');
  # Returns: ('ok')
