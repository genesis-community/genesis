=head1 NAME

Genesis::Secret::Random - Secret subclass for randomly generated strings

=head1 SYNOPSIS

  use Genesis::Secret;

  # Build a random secret via the factory method
  my $secret = Genesis::Secret->build('random', 'kit', 'myenv/secret:value',
    size       => 32,
  );

  # Build with a format variant stored under a separate key
  my $secret = Genesis::Secret->build('random', 'kit', 'myenv/secret:value',
    size   => 32,
    format => 'base64',
  );

  # Get the Vault operator string for use in BOSH manifests
  my $op = $secret->vault_operator();

  # Check format-related paths
  my $fkey  = $secret->format_key();   # e.g. 'value-base64'
  my $fpath = $secret->format_path();  # e.g. 'myenv/secret:value-base64'

  # Retrieve all Vault paths this secret occupies
  my @paths = $secret->all_paths();

=head1 DESCRIPTION

C<Genesis::Secret::Random> is a concrete subclass of L<Genesis::Secret> that
manages randomly generated string secrets stored in Vault (via C<safe gen>).

A random secret has a required C<size> (number of bytes to generate) and
optional modifiers:

=over 4

=item * C<valid_chars> - restrict the character set used during generation

=item * C<format> - store an additional formatted variant of the value
(C<base64>, C<bcrypt>, C<crypt-md5>, C<crypt-sha256>, or C<crypt-sha512>)

=item * C<destination> - key name under which to store the formatted variant
(only legal when C<format> is set; defaults to C<< E<lt>keyE<gt>-E<lt>formatE<gt> >>)

=item * C<fixed> - boolean; when true the value is never overwritten by
rotate operations

=back

When a C<format> is specified the secret occupies two Vault keys: the raw
random value at the primary path, and the formatted value at the format path.
Both paths are tracked and removed together.

Instances are not constructed directly; use C<< Genesis::Secret->build() >>.

=head1 METHODS

=head2 format_key

  my $key = $secret->format_key();

Returns the Vault key name under which the formatted variant of the secret is
stored. If no C<format> option was given, returns C<undef>.

When C<destination> is not set the key is derived automatically as
C<< E<lt>primary-keyE<gt>-E<lt>formatE<gt> >> (e.g. C<value-base64> when the
primary key is C<value> and the format is C<base64>). When C<destination> is
set, that value is returned instead.

B<Returns:> The formatted-value key name as a string, or C<undef> if the
secret has no format.

  my $secret = Genesis::Secret->build('random', 'kit', 'myenv/secret:value',
    size => 32, format => 'base64',
  );
  print $secret->format_key(); # prints 'value-base64'

  my $secret2 = Genesis::Secret->build('random', 'kit', 'myenv/secret:value',
    size => 32,
  );
  print defined($secret2->format_key()) ? 'defined' : 'undef'; # prints 'undef'

=head2 format_path

  my $path = $secret->format_path();

Returns the relative Vault path (including key) where the formatted variant is
stored. Returns C<undef> (empty return) if the secret has no format.

The path is assembled from the path portion of the secret's Vault path combined
with C<format_key()>, e.g. C<myenv/secret:value-base64>.

B<Returns:> The format path string in C<< E<lt>pathE<gt>:E<lt>keyE<gt> >>
form, or C<undef> if no format is configured.

  my $secret = Genesis::Secret->build('random', 'kit', 'myenv/secret:value',
    size => 32, format => 'bcrypt',
  );
  print $secret->format_path(); # prints 'myenv/secret:value-bcrypt'

=head2 set_format_value

  $secret->set_format_value($value, %opts);

Stores the formatted variant value on the object. Modifies the object
in-place.

B<Parameters:>

=over 4

=item * C<$value> - the formatted value to store

=item * C<%opts> - optional key/value pairs. Recognised keys:

=over 4

=item * C<in_sync =E<gt> $bool> - if true, the value is immediately promoted
to stored status (moved from the pending C<format_value> slot to the
C<stored_format_value> slot), indicating it matches what is in the backing
store

=back

=back

B<Returns:> Does not return a meaningful value.

  $secret->set_format_value('aGVsbG8=');
  print $secret->format_value(); # prints 'aGVsbG8='

  $secret->set_format_value('aGVsbG8=', in_sync => 1);
  # value is now in stored_format_value

=head2 format_value

  my $val     = $secret->format_value();
  my $present = $secret->has_format_value();

C<format_value> returns the formatted variant value, checking both the
pending slot and the stored slot. Returns the pending value if present,
otherwise the stored value. Returns C<undef> if neither is set.

C<has_format_value> returns true if a formatted variant value is present in
either slot. Unlike C<format_value>, it returns true even for a
defined-but-false value (e.g. an empty string).

B<Returns:> C<format_value> returns the formatted value string, or C<undef>.
C<has_format_value> returns a boolean.

  print $secret->format_value(); # prints the formatted value or undef

  if ($secret->has_format_value()) {
      print "format value present\n"; # prints 'format value present'
  }

=head2 vault_operator

  my $op = $secret->vault_operator($req_key);

Returns the Vault operator string for the primary random value, suitable for
embedding in a BOSH manifest. The key is taken from the path portion of the
secret's path; if the path has no explicit key segment, C<default_key()>
(C<'value'>) is used as the fallback. The C<$req_key> parameter is accepted
but not used.

B<Parameters:>

=over 4

=item * C<$req_key> - accepted but unused; the key is always derived from the
secret's own path

=back

B<Returns:> A BOSH C<(( vault ... ))> operator string.

  my $secret = Genesis::Secret->build('random', 'kit', 'myenv/secret:token',
    size => 32,
  );
  print $secret->vault_operator();
  # prints '(( vault meta.vault "/myenv/secret:token" ))'

=head2 default_key

  my $key = $secret->default_key();

Returns C<'value'>, the default Vault key name used when the path has no
explicit key segment. Overrides the L<base class|Genesis::Secret/default_key>, which returns C<undef>.

B<Returns:> The string C<'value'>.

  print $secret->default_key(); # prints 'value'

=head2 check_value

  my ($status, $msg) = $secret->check_value();

Checks whether the secret's primary value is present and, when a format is
configured, whether the formatted variant value is also present.

Returns C<('missing')> if the primary value is not defined. Returns C<('ok')>
if the primary value is present and either no format is configured or the
formatted variant value is also present. Returns C<('missing', $msg)> if the
primary value is present but the formatted variant is missing; C<$msg>
includes a checkbox indicator, the format name, and the format key.

B<Returns:> A list of C<($status)> or C<($status, $message)>.

  my ($status) = $secret->check_value();
  print $status; # prints 'ok' or 'missing'

=head2 promote_value_to_stored

  $secret->promote_value_to_stored();

Promotes the pending primary value to stored status (via the parent
implementation) and, if a format path is configured, also promotes the pending
format value to stored status. Modifies the object in-place. Does not return a
meaningful value.

  $secret->set_value('abc123');
  $secret->set_format_value('YWJjMTIz');
  $secret->promote_value_to_stored();
  print $secret->loaded(); # prints '1'

The complement C<reset> clears the in-memory value, stored value, format
value, and stored format value, and marks the secret as not loaded. It calls
the parent C<reset> implementation and then removes the format-specific
fields. Modifies the object in-place. Does not return a meaningful value.

  $secret->reset();
  print $secret->loaded(); # prints '0'
  print defined($secret->format_value()) ? 'defined' : 'undef'; # prints 'undef'

=head2 all_paths

  my @paths = $secret->all_paths();

Returns all Vault paths occupied by this secret. Always includes the primary
path from the inherited L<path|Genesis::Secret/path> accessor. Also includes the result of
C<format_path()> when
a format is configured and that method returns a defined value.

B<Returns:> A list of path strings.

  # Secret with no format
  my @paths = $secret->all_paths();
  print scalar(@paths); # prints '1'

  # Secret with format
  my @paths = $secret_with_format->all_paths();
  print scalar(@paths); # prints '2'

=head1 INTERNAL METHODS

These methods are internal to the implementation. They may change without
notice and should not be called directly.

=head2 _description

  my ($label, @features) = $secret->_description($alternative);

Returns the label and feature list used by the parent L<describe|Genesis::Secret/describe> method to build a human-readable description. When
C<$alternative> is C<'format'>, returns the label and a description of the
formatted value (format name and source path). Otherwise returns the label,
the size in bytes, and C<'fixed'> if the secret is fixed.

B<Parameters:>

=over 4

=item * C<$alternative> (optional) - when set to C<'format'>, returns the
description for the formatted variant rather than the primary value

=back

B<Returns:> A list of C<($label, @features)>.

  # Primary description
  my ($label, @feat) = $secret->_description();
  print "$label: ", join(', ', grep {$_} @feat); # prints e.g. 'Random: 32 bytes'

  # Format variant description
  my ($label, @feat) = $secret->_description('format');
  print "$label: ", join(', ', grep {$_} @feat);
  # prints e.g. 'Random: base64 formatted value of myenv/secret:value'

=head2 _validate_constructor_opts

  my ($args) = $class->_validate_constructor_opts($path, %opts);
  my ($orig_opts, $errors) = $class->_validate_constructor_opts($path, %opts);

Validates the constructor options for a random secret definition. Called by
the parent L<validate_definition|Genesis::Secret/validate_definition> method.

Recognised options:

=over 4

=item * C<size> (required) - a non-zero positive integer specifying the number
of bytes to generate. Produces error C<"Requires a non-zero positive integer
for 'size'"> if absent or zero.

=item * C<format> (optional) - one of C<base64>, C<bcrypt>, C<crypt-md5>,
C<crypt-sha256>, or C<crypt-sha512>

=item * C<destination> (optional, only valid when C<format> is set) - key name
for the formatted value

=item * C<valid_chars> (optional) - character class string restricting
generated characters

=item * C<fixed> (optional) - boolean; prevents overwriting on rotate

=back

Any unrecognised key produces the error C<"Invalid '$_' argument specified">
where C<$_> is the key name.

On success returns a single-element list containing the validated args
hashref. On failure returns the original opts hashref and an arrayref of
error strings.

  my ($args) = $class->_validate_constructor_opts('myenv/secret', size => 32);
  print $args->{size}; # prints '32'

  my ($orig, $errs) = $class->_validate_constructor_opts('myenv/secret');
  print $errs->[0]; # prints "Requires a non-zero positive integer for 'size'"

=head2 _validate_value

  my ($results, @order) = $secret->_validate_value(%opts);

Validates the current value against the secret's definition. Called by
the parent L<validate_value|Genesis::Secret/validate_value> method.

Options:

=over 4

=item * C<allow_oversized> (optional) - if true, values longer than C<size>
are accepted; otherwise the value must be exactly C<size> characters

=back

Checks performed (returned in order C<length>, C<valid_chars>, C<formatted>):

=over 4

=item * C<length> - value length matches C<size> (or meets the C<size> minimum
when C<allow_oversized> is true)

=item * C<valid_chars> - if C<valid_chars> is set, the value contains only
characters from that set

=item * C<formatted> - if a format is configured, the formatted variant value
is present

=back

Returns a hashref of C<< { check_name => [$status, $message] } >> and an
ordered list of check names.

  my ($results, @order) = $secret->_validate_value();
  print $results->{length}[0]; # prints 'ok' or 'warn'

=head2 _get_safe_command_for_remove

  my @cmd = $secret->_get_safe_command_for_remove();

Returns the safe command array to remove this secret from the backing store.
Generates a C<rm -f> command for the primary path. If a format is configured,
appends a second C<rm -f> command for the format path, separated by C<-->.

=head2 __get_safe_command_for_generate

  my @cmd = $secret->__get_safe_command_for_generate($action, %opts);

Shared implementation for building the C<safe gen> command used by both the
add and rotate operations. C<$action> is C<'add'> or C<'rotate'>. Adds
C<--no-clobber> when the action is C<'add'> or the secret is fixed. When a
format is configured, appends a C<safe fmt> sub-command separated by C<-->.

C<%opts> is accepted for interface uniformity but no keys are consumed by
this method.

B<Returns:> A list of command tokens suitable for passing to C<safe>.

  my @cmd = $secret->__get_safe_command_for_generate('add');
  print $cmd[0]; # prints 'gen'

=head2 _get_safe_command_for_add

  my @cmd = $secret->_get_safe_command_for_add(%opts);

Delegates to C<__get_safe_command_for_generate> with action C<'add'>,
passing any C<%opts> through to that method.

B<Parameters:>

=over 4

=item * C<%opts> - optional key/value pairs passed through to
C<__get_safe_command_for_generate>; no keys are consumed by this wrapper

=back

B<Returns:> A list of command tokens suitable for passing to C<safe>.

  my @cmd = $secret->_get_safe_command_for_add();
  print $cmd[0]; # prints 'gen'

=head2 _get_safe_command_for_rotate

  my @cmd = $secret->_get_safe_command_for_rotate();

Delegates to C<__get_safe_command_for_generate> with action C<'rotate'>.

B<Returns:> A list of command tokens suitable for passing to C<safe>.

=head2 _import_from_credhub

  my ($status) = $secret->_import_from_credhub($value);

Imports the secret value from CredHub by setting the in-memory value to
C<$value> and immediately saving it to the backing store. Returns C<('ok')>
on success.

B<Parameters:>

=over 4

=item * C<$value> - the plaintext value fetched from CredHub

=back

B<Returns:> C<('ok')>.

  my ($status) = $secret->_import_from_credhub('hunter2');
  print $status; # prints 'ok'
