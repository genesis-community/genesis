=head1 NAME

Genesis::Secret::DHParams - Genesis secret type for Diffie-Hellman parameters

=head1 SYNOPSIS

  use Genesis::Secret;

  # Build a DH parameters secret via the factory method
  my $secret = Genesis::Secret->build('dhparams', 'kit', 'path/to/dhparams',
    size => 2048,
  );

  # Build a fixed (non-rotatable) DH parameters secret
  my $fixed = Genesis::Secret->build('dhparams', 'kit', 'path/to/dhparams',
    size => 4096,
    fixed => 1,
  );

  # Check the human-readable label for this secret type
  print $secret->label();
  # Returns: 'Diffie-Hellman parameters'

=head1 DESCRIPTION

C<Genesis::Secret::DHParams> is the concrete C<Genesis::Secret> subclass for
Diffie-Hellman parameter secrets. It manages a DH parameter set stored in
Vault under a single path with one key: C<dhparam-pem> (the PEM-encoded DH
parameters).

The parameters are generated via C<safe dhparam> and are validated using
C<openssl dhparam> to verify that the PEM is well-formed, passes OpenSSL's
internal consistency check, and that the parameter size matches the configured
bit length.

Instances are created via C<< Genesis::Secret->build('dhparams', ...) >>. Do
not instantiate this class directly.

=head1 METHODS

=head2 label

  my $label = $secret->label();

Returns the human-readable label C<'Diffie-Hellman parameters'> for this
secret type. Overrides the L<base class default|Genesis::Secret/label>.

B<Returns:> The string C<'Diffie-Hellman parameters'>.

  print $secret->label();
  # Returns: 'Diffie-Hellman parameters'

=head2 process_command_output

  my ($out, $rc, $err) = $secret->process_command_output($action, $out, $rc, $err);

Post-processes the output from a C<safe dhparam> command. Overrides the L<base class implementation|Genesis::Secret/process_command_output> to suppress the verbose dot-progress output that OpenSSL
prints during DH parameter generation.

For the C<'add'> action, if C<$out> matches the pattern produced by a
successful generation run (ending with C<++*++*>), C<$out> is replaced with
an empty string. For all other actions the output is returned unchanged.

B<Parameters:>

=over 4

=item * C<$action> - The action that was performed: C<'add'>, C<'rotate'>, or
C<'remove'>.

=item * C<$out> - Standard output from the safe command.

=item * C<$rc> - Exit code from the safe command.

=item * C<$err> - Standard error output from the safe command.

=back

B<Returns:> A list of C<($out, $rc, $err)> with C<$out> potentially replaced
by an empty string for successful C<'add'> operations.

  my ($out, $rc, $err) = $secret->process_command_output('add',
    "Generating DH parameters, 2048 bit long safe prime ...\n++*++*",
    0, '',
  );
  print $out; # Returns: ''

  my ($out, $rc, $err) = $secret->process_command_output('rotate', "ok\n", 0, '');
  print $out; # Returns: 'ok'

=head1 INTERNAL METHODS

These methods are internal to the implementation. They may change without
notice and should not be called directly.

=head2 _description

  my ($label, @features) = $secret->_description();

Returns a list describing the DH parameters for use by the parent L<describe|Genesis::Secret/describe> method. The list contains the string C<"Diffie-Hellman key
exchange parameters">, the configured size in bits (e.g., C<"2048 bits">),
and the string C<'fixed'> if the secret is marked fixed (or C<undef> for
that slot if not fixed).

=head2 _required_constructor_opts

  my @opts = $secret->_required_constructor_opts();

Returns C<('size')>, indicating that the C<size> option (parameter bit length)
is required when constructing a DHParams secret.

=head2 _optional_constructor_opts

  my @opts = $secret->_optional_constructor_opts();

Returns C<('fixed')>, indicating that the C<fixed> boolean option is accepted
but not required.

=head2 _required_value_keys

  my @keys = $secret->_required_value_keys();

Returns C<('dhparam-pem')>, the single key that must be present in the stored
value hashref for the secret to be considered complete.

=head2 _validate_value

  my ($results, @order) = $secret->_validate_value(%opts);

Validates the stored DH parameters using C<openssl dhparam>. Checks that the
PEM data is well-formed and passes OpenSSL's consistency check, and that the
parameter bit length matches the configured C<size>.

B<Parameters:>

=over 4

=item * C<%opts> - Options hash. Accepts:

=over 4

=item * C<allow_oversized> - If true, accepts parameters larger than the
configured C<size> (only requires the parameter set to be at least C<size>
bits). Defaults to false (exact match required).

=back

=back

B<Returns:> A list of C<(\%results, @order)> where C<%results> is a hash
mapping validation names to C<[$status, $message]> pairs, and C<@order> is
C<('valid', 'size')> giving the display order.

The C<'valid'> entry reports whether OpenSSL confirmed the PEM is well-formed.
The C<'size'> entry reports whether the bit length matches the configured size,
including C<'minimum'> in the label when C<allow_oversized> is true and
noting the actual found size when it differs.

  my ($results, @order) = $secret->_validate_value();
  # Returns: (\%results, 'valid', 'size')

  my ($results, @order) = $secret->_validate_value(allow_oversized => 1);
  # Returns: (\%results, 'valid', 'size') with size check requiring >= configured bits

=head2 __get_safe_command_for_generate

  my @cmd = $secret->__get_safe_command_for_generate($action, %opts);

Constructs the C<safe dhparam> command argument list for generating the DH
parameters. Appends C<--no-clobber> when C<$action> is C<'add'> or when the
secret is marked as fixed.

B<Parameters:>

=over 4

=item * C<$action> - The generation action: C<'add'> or C<'rotate'>.

=item * C<%opts> - Currently unused; accepted for interface compatibility.

=back

B<Returns:> A list beginning with C<'dhparam'>, followed by the configured
parameter size and the full Vault path, optionally with C<'--no-clobber'>.

  my @cmd = $secret->__get_safe_command_for_generate('add');
  # Returns: ('dhparam', 2048, 'secret/myenv/path/to/dhparams', '--no-clobber')

  my @cmd = $secret->__get_safe_command_for_generate('rotate');
  # Returns: ('dhparam', 2048, 'secret/myenv/path/to/dhparams')

=head2 _get_safe_command_for_add

  my @cmd = $secret->_get_safe_command_for_add();

Delegates to C<__get_safe_command_for_generate> with action C<'add'>.
Called by the parent L<get_safe_command_for|Genesis::Secret/get_safe_command_for> dispatch for the C<'add'>
action.

B<Returns:> The same list as C<__get_safe_command_for_generate> with
C<--no-clobber> always appended.

=head2 _get_safe_command_for_rotate

  my @cmd = $secret->_get_safe_command_for_rotate();

Delegates to C<__get_safe_command_for_generate> with action C<'rotate'>.
Called by the parent L<get_safe_command_for|Genesis::Secret/get_safe_command_for> dispatch for the C<'rotate'>
action.

B<Returns:> The same list as C<__get_safe_command_for_generate>, with
C<--no-clobber> appended only if the secret is marked fixed.
