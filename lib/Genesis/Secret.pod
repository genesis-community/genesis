=encoding UTF-8

=head1 NAME

Genesis::Secret - Base class for all Genesis secret types

=head1 SYNOPSIS

  use Genesis::Secret;

  # Build a secret via the factory method (never call new directly)
  my $secret = Genesis::Secret->build('random', 'kit', 'path/to/secret',
    length => 32,
  );

  # Check if the secret exists in the store
  if ($secret->exists) {
      print "Value: ", $secret->value, "\n";
  }

  # Describe the secret
  my $desc = $secret->describe();
  print "Description: $desc\n";

  # Save/load from the backing store
  $secret->load;
  $secret->save;

=head1 DESCRIPTION

C<Genesis::Secret> is the abstract base class for all secret types in the
Genesis secrets management system. It provides the common interface for
creating, loading, saving, validating, and describing secrets stored in
Vault (via C<safe>).

This class cannot be instantiated directly. Use C<build()> to create
instances of derived classes such as C<Genesis::Secret::Random>,
C<Genesis::Secret::X509>, C<Genesis::Secret::SSH>, etc.

Each secret has a Vault path, a definition (from kit or manifest), and a
value that can be loaded from and saved to the backing store. Secrets
track their source (kit feature or manifest variable) and support
validation, CredHub import, and safe command generation.

=head1 METHODS

=head2 new

  my $secret = $class->new($path, %opts);

Constructor called by derived classes. Creates a new secret object at
the given Vault C<$path> with options specific to the derived type.

Valid keys in C<%opts> are determined by the derived class through its
C<_required_constructor_opts> and C<_optional_constructor_opts> methods.
The constructor passes C<%opts> to C<validate_definition()>, which checks
that all required keys are present and no unknown keys are supplied.

Two keys are reserved for internal use by the framework:

=over 4

=item * C<_ch_name> - CredHub variable name, set when the secret
originates from a manifest. Recorded as C<source =E<gt> 'manifest'>.

=item * C<_feature> - Kit feature name, set when the secret is defined
by a kit feature. Recorded as C<source =E<gt> 'kit'>.

=back

These internal keys are stripped from C<%opts> before validation and
stored separately on the object. They are re-attached to the definition
if validation fails so the rejection can report the source.

Returns a C<Genesis::Secret::Invalid> object if validation fails.

Dies if called directly on C<Genesis::Secret>:

=over 4

=item * C<"Cannot directly instantiate a Genesis::Secret - use build to instantiate a derived class">

=back

  # Called internally by derived classes, not directly
  my $secret = Genesis::Secret::Random->new('path/to/secret', length => 32);
  print ref($secret); # prints 'Genesis::Secret::Random'

=head2 build

  my $secret = Genesis::Secret->build($type, $source, $path, %definition);

Factory method that creates a secret of the given C<$type> (e.g., C<'random'>,
C<'x509'>, C<'ssh'>). C<$source> records the originating context (e.g., C<'kit'>
or C<'manifest'>) but is not used by the base implementation — it is accepted for
forward compatibility and caller documentation purposes. Resolves the type name to
its class via L</class_of>, loads the module, and calls its constructor.

Returns a C<Genesis::Secret::Invalid> object if the type is unknown or
the constructor fails.

Dies if called on a derived class instead of C<Genesis::Secret>:

=over 4

=item * C<"Cannot call build on %s -- use build on Genesis::Secret">

=back

  # Build a random secret
  my $secret = Genesis::Secret->build('random', 'kit', 'my/secret',
    length => 32,
  );
  print ref($secret); # prints 'Genesis::Secret::Random'

=head2 save

  $secret->save();

Writes the secret's current value to the backing store via
C<< $secret->plan->store->write >>. Does not return a meaningful value.

  # Persist the current value
  $secret->set_value('hunter2');
  $secret->save();
  # writes to vault (no return value)

=head2 load

  $secret->load();

Reads the secret's value from the backing store via
C<< $secret->plan->store->read >>. Does not return a meaningful value.

  # Load the secret from vault
  $secret->load;
  print $secret->value(); # prints the stored value

=head2 autoload

  $secret->autoload();

Loads the secret from the store if the C<autoload> flag on the object
is true and the secret has not already been loaded. The C<autoload> flag
is initialized to C<0> by the constructor; external code must set
C<< $self->{autoload} >> to a true value for this method to trigger a
load. Does not return a meaningful value.

  # Autoload is triggered internally by value() and has_value()
  $secret->autoload();
  # loads from store only if $self->{autoload} is true

=head2 exists

  my $bool = $secret->exists();

Returns true if the secret has a value, either already loaded in memory
or present in the backing store.

  if ($secret->exists) {
      print "Secret is available\n"; # prints 'Secret is available'
  }

=head2 reset

  $secret->reset();

Clears the in-memory value and stored value, and marks the secret as
not loaded. Modifies the object in-place. Does not return a meaningful
value.

  $secret->reset();
  print $secret->loaded(); # prints '0'

=head2 remove

  $secret->remove();

Removes the secret from the backing store and resets the in-memory state.
Does not return a meaningful value.

  # Delete from vault and clear local state
  $secret->remove();
  # removes from backing store and resets local state

=head2 reject

  my $invalid = Genesis::Secret->reject($subject, $errors, $path, $args);
  my $invalid = $secret->reject($subject, $errors, $path, $args);

Creates a C<Genesis::Secret::Invalid> object representing a validation
failure. Can be called as a class method or instance method. The first
argument (C<$class_or_ref>) is the invocant. When called on an instance,
C<$path> and C<$args> default to the instance's path and definition.

C<$subject> is a label for the error (typically the secret type).
C<$errors> is an array reference of error message strings.

Returns the C<Genesis::Secret::Invalid> object.

  my $invalid = Genesis::Secret->reject(
    'random', ['Missing length'], 'path/to/secret', {}
  );
  print ref($invalid); # prints 'Genesis::Secret::Invalid'

=head2 validate_definition

  my ($args, $errors, $path) = $class->validate_definition($path, %opts); # on failure
  my ($args, $path)          = $class->validate_definition($path, %opts); # on success

Validates the constructor options for a secret definition. If the
derived class implements C<_validate_constructor_opts>, delegates to that.
Otherwise uses C<_required_constructor_opts> and
C<_optional_constructor_opts> to check for missing or unknown arguments.

Returns a list of C<($args_hashref, $errors_arrayref, $path)> on failure,
or C<($args_hashref, $path)> on success.

Skips validation entirely if C<GENESIS_SKIP_SECRET_DEFINITION_VALIDATION>
is set in the environment.

  my ($args, $errors) = Genesis::Secret::Random->validate_definition(
    'path/to/secret', length => 32
  );
  print "Valid\n" if !ref($errors); # prints 'Valid'

=head2 path

  my $path = $secret->path();

Returns the Vault path for this secret (relative to the store base).

Note: several accessor methods defined alongside this one delegate through
the plan object. Those methods die if the secret has not been assigned to
a plan. See L</plan> for details.

Dies (via the plan accessor):

=over 4

=item * C<"Secret not in a plan -- cannot continue">

=back

  print $secret->path(); # prints e.g. 'path/to/secret'

=head2 all_paths

  my @paths = $secret->all_paths();

Returns all Vault paths associated with this secret. For the base class
this returns a single-element list containing C<path()>. Derived classes
may override to return multiple paths (e.g., X509 certificates with
separate key and certificate paths).

  my @paths = $secret->all_paths();
  print join(', ', @paths); # prints e.g. 'path/to/secret'

=head2 full_path

  my $full = $secret->full_path();

Returns the fully qualified Vault path, including the store's base path
prefix.

  print $secret->full_path(); # prints e.g. 'secret/myenv/path/to/secret'

=head2 default_key

  my $key = $secret->default_key();

Returns the default Vault key for this secret type, or C<undef>. Derived
classes override this to specify which key within the Vault path holds
the primary value.

  my $key = $secret->default_key();
  print defined($key) ? $key : 'undef'; # prints 'undef' for base class

=head2 definition

  my $def = $secret->definition();

Returns the hashref of definition options that were passed to the
constructor.

  my $def = $secret->definition();
  print $def->{length}; # prints e.g. '32'

=head2 value

  my $val = $secret->value();

Returns the secret's current value. Triggers C<autoload()> if the secret
has not been loaded yet. Returns the pending value if set, otherwise the
stored value.

  my $val = $secret->value();
  print $val; # prints the secret value

=head2 has_value

  my $bool = $secret->has_value();

Returns true if the secret has a stored value. Triggers C<autoload()>
first.

  if ($secret->has_value) {
      print "Has value\n"; # prints 'Has value'
  }

=head2 loaded

  my $bool = $secret->loaded();

Returns true if the secret has been loaded from the backing store.

  $secret->load;
  print $secret->loaded(); # prints '1'

=head2 missing

  my $bool = $secret->missing();

Returns true if the secret does not have a value. Equivalent to
C<< !$secret->has_value >>.

  if ($secret->missing) {
      print "Secret not found\n"; # prints 'Secret not found'
  }

=head2 set_plan

  $secret->set_plan($plan);

Sets the secrets plan that this secret belongs to. Returns the secret
object for chaining.

  $secret->set_plan($plan)->load();
  # returns $secret for chaining

=head2 plan

  my $plan = $secret->plan();

Returns the C<Genesis::Env::Secrets::Plan> that this secret belongs to.

Dies if the secret has not been assigned to a plan:

=over 4

=item * C<"Secret not in a plan -- cannot continue">

=back

  my $plan = $secret->plan();
  print ref($plan); # prints 'Genesis::Env::Secrets::Plan'

=head2 base_path

  my $base = $secret->base_path();

Returns the base path of the backing store, from
C<< $secret->plan->store->base >>.

  print $secret->base_path(); # prints e.g. 'secret/myenv/'

=head2 source

  my $src = $secret->source();

Returns the source of the secret definition: C<'kit'>, C<'manifest'>, or
empty string if unknown.

  print $secret->source(); # prints 'kit' or 'manifest'

=head2 from_kit

  my $bool = $secret->from_kit();

Returns true if the secret definition originated from a kit feature.

  print $secret->from_kit(); # prints '1' or ''

=head2 feature

  my $feat = $secret->feature();

Returns the kit feature name that defined this secret, or C<undef>.

  print $secret->feature(); # prints e.g. 'tls' or undef

=head2 from_manifest

  my $bool = $secret->from_manifest();

Returns true if the secret definition originated from a deployment
manifest.

  print $secret->from_manifest(); # prints '1' or ''

=head2 var_name

  my $name = $secret->var_name();

Returns the CredHub variable name from the manifest, or C<undef>.

  print $secret->var_name(); # prints e.g. '/bosh/myenv/my-secret'

=head2 credhub

  my $ch = $secret->credhub();

Returns the CredHub client from the secret's plan.

  my $ch = $secret->credhub();
  # returns Genesis::CredHub instance

=head2 type

  my $type = $secret->type();

Returns the lowercase type name derived from the class name. For example,
C<Genesis::Secret::Random> returns C<'random'>, C<Genesis::Secret::DHParams>
returns C<'dhparams'>.

  print $secret->type(); # prints 'random'

=head2 label

  my $label = $secret->label();

Returns the human-readable label for the secret type (ucfirst of
L</type>).

  print $secret->label(); # prints 'Random'

=head2 class_of

  my $class = Genesis::Secret::class_of($type);

Helper function (called with C<::>, not C<< -> >>). Returns the full
package name for a secret type string. Handles exceptions where
C<ucfirst($type)> does not match the actual class name.

  print Genesis::Secret::class_of('ssh');      # prints 'Genesis::Secret::SSH'
  print Genesis::Secret::class_of('dhparams'); # prints 'Genesis::Secret::DHParams'
  print Genesis::Secret::class_of('random');   # prints 'Genesis::Secret::Random'

=head2 valid

  my $bool = $secret->valid();

Returns true if the secret definition is valid. The base class always
returns true; derived classes override to perform type-specific
validation.

  print $secret->valid(); # prints '1'

=head2 check_value

  my ($status, $msg) = $secret->check_value();

Checks whether the secret's value is present and complete. If the secret
type defines C<_required_value_keys>, checks that the value is a hashref
containing all required keys.

Returns C<('ok')> if the value is present and complete, or
C<('missing')> with an optional message listing missing keys.

  my ($status) = $secret->check_value();
  print $status; # prints 'ok' or 'missing'

=head2 validate_value

  my ($status, $msg) = $secret->validate_value($plan, %opts);

Validates the secret's value for correctness. First calls
C<check_value()> to verify presence, then delegates to C<_validate_value>
if implemented by the derived class. C<%opts> is passed through to
the derived class's C<_validate_value> method; accepted options depend
on the derived class implementation.

Validation messages are filtered by the C<GENESIS_HIDE_PROBLEMATIC_SECRETS>
environment variable. When set, only messages at the highest severity
level are included in the output.

Returns a status string (C<'ok'>, C<'warn'>, or C<'error'>) and a
message describing the validation results.

  my ($status, $msg) = $secret->validate_value($plan);
  print "$status: $msg\n"; # prints e.g. 'ok: '

=head2 get_safe_command_for

  my @cmd = $secret->get_safe_command_for($action, %opts);

Returns the safe/vault command array for performing C<$action> on this
secret. Uses dynamic dispatch: if the derived class implements a method
named C<_get_safe_command_for_E<lt>actionE<gt>> (e.g.,
C<_get_safe_command_for_add>), delegates to that method with C<%opts>.
The C<'remove'> action is handled by the base class and returns
C<('rm', '-f', $self-E<gt>full_path)>. C<%opts> are passed through to
the dispatched method; accepted options depend on the action and derived
class.

Dies if the action is not C<'remove'> and no dispatch method exists:

=over 4

=item * C<"Class %s does not provide command to %s secrets from safe/vault">

where C<%s> is the class name and the action string, respectively.

=back

  my @cmd = $secret->get_safe_command_for('remove');
  # Returns: ('rm', '-f', 'secret/myenv/path/to/secret')

=head2 process_command_output

  my ($out, $rc, $err) = $secret->process_command_output($action, $out, $rc, $err);

Post-processes the output from a safe/vault command. C<$action> is the
action string (e.g., C<'add'>, C<'remove'>). C<$out> is the command's
standard output. C<$rc> is the exit code. C<$err> is the standard error
output. The base class strips leading whitespace from C<$out> and
returns C<($out, $rc, $err)> unchanged otherwise. Derived classes may
override for type-specific processing.

  my ($out, $rc, $err) = $secret->process_command_output('add', "  ok\n", 0, '');
  print $out; # prints "ok\n" (leading whitespace stripped)

=head2 import_from_credhub

  my ($status, $msg) = $secret->import_from_credhub();

Imports the secret's value from CredHub. Requires the secret to have
originated from a manifest (C<from_manifest> must be true and
C<var_name> must be set).

Returns C<('error', $message)> if the secret is not from a manifest or
if the CredHub fetch fails. On success, delegates to the derived class's
C<_import_from_credhub> implementation, passing the fetched CredHub
value. The return value is whatever C<_import_from_credhub> returns
(typically a C<($status, $message)> pair).

  my ($status, $msg) = $secret->import_from_credhub();
  print "$status\n"; # prints 'error' if not from manifest

=head2 is_command_interactive

  my $bool = $secret->is_command_interactive();

Returns true if the safe command for this secret type requires interactive
input. The base class returns false; derived classes (e.g.,
C<Genesis::Secret::UserProvided>) may override.

  print $secret->is_command_interactive(); # prints '0'

=head2 describe

  my $desc = $secret->describe($alternative);
  my ($path, $label, $features) = $secret->describe($alternative);

Returns a human-readable description of the secret. C<$alternative> is
an optional value passed through to the derived class's C<_description>
method, allowing it to return an alternate description variant. In
scalar context, returns a formatted string combining the label and
features. In list context, returns the path, label, and comma-separated
features.

If the derived class does not implement C<_description>, returns a
default string of the form C<"Label secret">.

  # Scalar context
  print $secret->describe(); # prints e.g. 'Random secret - 32 bytes'

  # List context
  my ($path, $label, $features) = $secret->describe();
  print "$path: $label ($features)\n";
  # prints e.g. 'path/to/secret: Random (32 bytes)'

=head2 get

  my $val = $secret->get($property, $default);

Returns the value of C<$property> from the secret's definition, or
C<$default> if not set.

  my $length = $secret->get('length', 32);
  print $length; # prints '32'

=head2 has

  my $bool = $secret->has($property);

Returns true if C<$property> exists in the secret's definition.

  print $secret->has('length'); # prints '1' or ''

=head2 set

  $secret->set($property, $value);

Sets C<$property> to C<$value> in the secret's definition. Returns the
new value. Does not re-validate the definition after modification;
callers are responsible for ensuring the resulting definition remains
valid.

  my $val = $secret->set('length', 64);
  print $val; # prints '64'

=head2 set_value

  $secret->set_value($value, %opts);

Sets the secret's in-memory value via C<_set_value()>. Modifies the
object in-place. Does not return a meaningful value.

Options:

=over 4

=item * C<in_sync> - If true, moves the value from C<{value}> (pending)
to C<{stored_value}> immediately, indicating it matches what is in the
backing store.

=item * C<loaded> - If true, marks the secret as loaded (sets
C<< $self->{loaded} >> to C<1>). Defaults to false, which sets
C<{loaded}> to C<0>.

=back

  $secret->set_value('new-secret-data', in_sync => 1, loaded => 1);
  # sets value, promotes to stored, and marks as loaded

=head2 update_value

  $secret->update_value($value, %opts);

Merges C<$value> into the secret's current value. If both the current
value and C<$value> are hashrefs, performs a shallow merge (keys in
C<$value> overwrite same-named keys in the current value; nested
hashrefs are not merged recursively). Otherwise replaces the value
entirely. Passes C<%opts> through to C<set_value()>. Does not return a
meaningful value.

  # Shallow merge: existing {a => 1, b => 2} + {b => 9, c => 3}
  $secret->update_value({b => 9, c => 3}, in_sync => 1);
  # Returns: value is now {a => 1, b => 9, c => 3}

  # Non-hash value: replaces entirely
  $secret->update_value('new-password');
  # Returns: value is now 'new-password'

=head2 promote_value_to_stored

  $secret->promote_value_to_stored();

Moves the pending value (C<< $self->{value} >>) into stored status
(C<< $self->{stored_value} >>) and sets C<loaded> to true. After this
call, C<< $self->{value} >> is deleted and L</value> will return the
stored value. Modifies the object in-place. Does not return a meaningful
value.

  $secret->set_value('pending-data');
  $secret->promote_value_to_stored();
  print $secret->loaded(); # prints '1'
  print $secret->value();  # prints 'pending-data' (now stored)

=head1 ABSTRACT METHODS

Methods that derived classes B<must> implement. The base class will die
(via C<bug()>) if these are not overridden.

=head2 _required_constructor_opts

Must return a list of required constructor option names for the secret
type.

Dies with C<"%s did not define _required_contructor_opts"> if not overridden,
where C<%s> is the class name.

  # In a derived class:
  sub _required_constructor_opts { qw(length) }
  # Returns: ('length')

=head2 _optional_constructor_opts

Must return a list of optional constructor option names for the secret
type.

Dies with C<"%s did not define _optional_constructor_opts"> if not overridden,
where C<%s> is the class name.

  # In a derived class:
  sub _optional_constructor_opts { qw(format encoding) }
  # Returns: ('format', 'encoding')

=head1 OVERRIDE POINTS

Methods that derived classes B<may> implement to customize behavior. The
base class either provides a default implementation or checks for
the method via C<can()> before calling.

=head2 _validate_constructor_opts

  my ($args, $errors, $path) = $class->_validate_constructor_opts($path, %opts);

If implemented, C<validate_definition()> delegates entirely to this
method instead of using the required/optional option lists. Use this for
secret types with complex validation logic.

=head2 _validate_value

  my ($results, @validations) = $self->_validate_value(%opts);

If implemented, C<validate_value()> calls this after C<check_value()>
passes. Should return a hashref of results keyed by validation name
(each value is C<[$status, $message]>), and an ordered list of
validation names.

=head2 _description

  my ($label, @features) = $self->_description($alternative);

If implemented, C<describe()> uses the returned label and feature list
to build the description string. If not implemented, C<describe()>
returns a default C<"Label secret"> string.

=head2 _set_value

  $secret->_set_value($value);

Default implementation stores C<$value> in C<< $self->{value} >>. Returns
the assigned value. Override in derived classes for secret types that
need special value processing (e.g., parsing structured data).

=head2 _import_from_credhub

  my ($status, $msg) = $self->_import_from_credhub();

Default returns C<('error', "Cannot import %s secrets from CredHub - not implemented")>
where C<%s> is the secret's type. The base implementation ignores the
C<$value> argument passed by C<import_from_credhub()>. Override to
accept and process C<$value> (the data fetched from CredHub, split on
C<.> from C<var_name>) and return a C<($status, $message)> pair.

=head2 _required_value_keys

Returns C<undef> by default. Override to return a list of required keys
that must be present in the secret's value hashref for C<check_value()>
to consider the value complete. This validates the B<stored value
structure>, not the constructor definition. For constructor option
validation, use C<_required_constructor_opts> or
C<_validate_constructor_opts> instead.

  # In a derived class:
  sub _required_value_keys { qw(certificate key) }

Derived classes may also implement dynamic dispatch methods named
C<_get_safe_command_for_add>, C<_get_safe_command_for_rotate>, etc.
as targets for C<get_safe_command_for()>.

=head1 INTERNAL METHODS

Private helper methods. These should not be called directly.

=head2 _assemble_vault_operator

  my $operator = $secret->_assemble_vault_operator($path);

Formats a Vault operator string for use in BOSH manifests. If C<$path>
starts with C</>, uses a direct vault reference. Otherwise, prepends
C<meta.vault> as a BOSH variable prefix. Returns a string suitable for
embedding in a BOSH manifest.

  my $op = $secret->_assemble_vault_operator('my/secret:key');
  print $op; # prints '(( vault meta.vault "/my/secret:key" ))'

  my $op2 = $secret->_assemble_vault_operator('/absolute/path:key');
  print $op2; # prints '(( vault "/absolute/path:key" ))'
